# Authentic NX screenshots

These seven PNG files were captured directly from the live Siemens NX window on 2026-10-11 using the computer-use skill. Five show the final `AI_SIM_TAKE_2` Solution 1 nodal temperature contour. Two show the hollow copper part geometry, including an end detail. The original screenshot files retain NX UI and model/result identification. Slides crop only the viewport area, without changing model geometry or temperature colors.

The contour screenshots use Celsius, smooth shading and hidden mesh edges. The color scales differ between rods because each retains its actual NX range. Compare absolute values using the legends rather than comparing colors alone. The screenshot ranges agree with the final Take2 reports. Native contour display settings were changed for readability, and no model or solver file was saved.

`capture_provenance.json` records the screenshot hashes, saved SIM/OP2 source hashes and observed temperature ranges. MATLAB graphs elsewhere in this package remain plots of measured and exported numerical data, not screenshots of NX.
