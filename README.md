# Experimental Methods — Group E (Fall 2026)

Shared working folder for the group: lecture transcripts and notes, Canvas material, all lab
data, NX models, MATLAB analysis, report decks, and per-experiment write-ups.

## Start here
- `CLAUDE.md` / `AGENTS.md` — context for an AI assistant (course, status, conventions, folder map).
  Open the folder in Claude Code, Codex or a similar tool and it picks these up automatically.
- `MEMORY.md` — running log of what's been done, newest first.
- `Notes/` — detailed write-ups per experiment (EXP1–EXP4).
